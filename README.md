### 🧑‍💻 Обо мне

Я системный администратор с опытом 1+ года, преподаватель программирования, который целенаправленно переходит в кибербезопасность. Владею практическими навыками:

- **Настройка SIEM** (Wazuh) в лабораторной среде с Docker.
- **Проведение пентестов** (сканирование, брутфорс, реверс-шелл) и их детекция.
- **OSINT-разведка** с интеграцией API (VirusTotal, Shodan, AbuseIPDB).
- **Автоматизация** сбора логов и их версионирование через Git и cron.
- **Администрирование** Windows/Linux, сетей (TCP/IP, DNS, DHCP), Active Directory.

Ищу позицию **Junior SOC Analyst** или **стажировку в области кибербезопасности**. Готов к переезду и удалённой работе.
